Photo transfer check

Copied photos off your phone? Check them here before you delete anything from the phone. Everything runs in your browser. No file is uploaded.

What does it check?

For every photo and video it reads the first bytes to see what the file really is (JPEG, HEIC, PNG, MOV, MP4 and a few more), then checks the file is whole. A video or HEIC photo is a set of boxes, and each box says how long it is. If a box needs more bytes than the file has, the copy stopped early. A JPEG or PNG must end with its end marker.

A cut-short file can still show a normal thumbnail, and some even open with a grey or green block where the picture ran out. That is why looking at previews is not enough.

How to copy from an iPhone so this doesn't happen
  1. On the iPhone: Settings → Photos → Transfer to Mac or PC → Keep Originals.
  2. Copy a few hundred at a time and keep the phone unlocked.
  3. Run this check. Only delete from the phone when it says it's safe.
